# 🍊 Swiggy Sales Analysis Dashboard | Microsoft Excel

An interactive sales analytics dashboard built using Microsoft Excel to analyze sales performance, customer ratings, order trends, food categories, and geographic distribution.

## 📊 Project Overview

This project focuses on transforming sales data into meaningful business insights through an interactive Excel dashboard. It provides a consolidated view of key performance indicators (KPIs) and visualizations to help understand sales patterns and business performance.

## 🎯 Project Objectives

- Analyze overall sales performance and order volume.
- Track monthly, daily, and weekly sales trends.
- Understand customer ratings and ordering behavior.
- Compare sales across food categories and states.
- Identify top-performing cities based on sales.
- Present key metrics through a clear, interactive dashboard.

## 📌 Key Performance Indicators (KPIs)

The dashboard highlights the following metrics:

| KPI | Description |
|---|---|
| Total Sales | Overall sales value |
| Average Rating | Average customer rating |
| Average Order Value | Average value per order |
| Rating Count | Total number of ratings recorded |
| Total Orders | Total number of orders |

## 📈 Dashboard Features

### 1. Monthly Sales Trend
Visualizes month-wise sales performance to identify trends and fluctuations over time.

### 2. Daily Sales Trend
Compares sales across the days of the week to understand daily sales patterns.

### 3. Sales by Food Type
Analyzes sales distribution between vegetarian and non-vegetarian food categories.

### 4. State-wise Sales Analysis
Displays geographic sales distribution across Indian states.

### 5. Sales, Ratings, and Orders by Quarter
Compares quarterly sales, average ratings, and order volumes.

### 6. Top 5 Cities by Sales
Highlights the cities contributing the highest sales.

### 7. Weekly Sales Trends
Shows weekly sales patterns to help identify changes in performance.

### 8. Interactive Filters
Allows users to explore the dashboard by available months, food categories, and restaurant names.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `Swiggy_Sales_Dashboard.xlsx` using Microsoft Excel.
3. Enable editing if prompted and review the dashboard.
4. Use the available filters and slicers to explore different sales segments.
5. Analyze the charts and KPIs to identify sales patterns and performance trends.

*Interactive functionality depends on the features supported by your Excel workbook and spreadsheet application.*
